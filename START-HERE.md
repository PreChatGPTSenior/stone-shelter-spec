# Start here

1. Read the [capability index](openspec/specs/README.md) and the relevant
   requirements and acceptance scenarios.
2. Use the visual references and acceptance matrix in product-baseline,
   qualification data in data, and Kafka schema in contracts.
3. Follow [environment-setup.md](environment-setup.md) to install and validate
   OpenSpec and the static analysis tools.
4. Before implementation, define the requested task batch with a readiness
   ticket first. Verify its prerequisites and agree any requirement changes.

The additional engineering guide is stored separately in reference.
OpenSpec requirements and scenarios define the application acceptance target.
Static analysis fixtures verify analyzer rules, not application acceptance.
